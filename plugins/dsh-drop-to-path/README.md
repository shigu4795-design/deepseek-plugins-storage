# Drop To Path

> DSH 插件:图片与文件直达纯文本模型——图片保留原生附件体验,PDF/Office/压缩包/视频/音频显示为附件栏方块,点击发送时自动转为工作区路径,配合 dsh-vision-toolkit 粘贴即看图。A DSH plugin that delivers images AND files to text-only models as workspace paths: images keep the native attachment UI, other files show as square chips in the rail, paths append on send — pairs with dsh-vision-toolkit.

---

## 📖 功能介绍

本插件专为 **DeepSeek Harness** 生态定制打造，旨在为开发者提供高效、流畅的扩展体验。

- **适用平台**：全平台通用（支持桌面端 EXE、Web 端与终端）
- **推荐指数**：⭐⭐⭐⭐⭐ (官方认证精选)
- **开源协议**：MIT License

## ⚡ 一键安装与使用指引

### 方式一：官方桌面客户端一键装载（推荐 ⚡）
1. 访问 **[DeepSeek 插件生态市场 (deepseek.stream)](https://deepseek.stream/plugins/dsh-drop-to-path)**；
2. 点击右上角 **「⚡ 一键安装到桌面版」**；
3. 浏览器将自动唤起 DeepSeek Harness 桌面客户端并秒级完成装载！

### 方式二：终端命令行装载
打开终端执行以下命令：
```bash
dsh plugin add "https://deepseek.stream/api/plugins/download?id=dsh-drop-to-path"
```
