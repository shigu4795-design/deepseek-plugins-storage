## ⚡ 极速安装与使用指南

### 方式一：官方桌面客户端一键装载（推荐 ⚡）
1. 访问 **[DeepSeek 插件生态市场 (deepseek.stream)](https://deepseek.stream/plugins/dsh-easyrewrite)**；
2. 在插件卡片右上角点击 **「⚡ 一键安装到桌面版」**；
3. 浏览器将自动唤醒 DeepSeek Harness 桌面客户端并秒级完成装载！

### 方式二：终端命令行安装
打开终端执行以下标准安装指令：
```bash
dsh plugin add "https://deepseek.stream/api/plugins/download?id=dsh-easyrewrite"
```
