## 📖 插件介绍

Import pi / opencode / codex / claude-code sessions, chat history, and agents into DeepSeek Harness — one-click Sync button, slash commands, session-start migration prompt

---

## ⚡ 安装方法

### 方法一：桌面客户端一键安装（推荐）
在 [DeepSeek 插件市场](https://deepseek.stream/plugins/dsh-import-agents) 点击 **「一键安装到桌面版」** 即可免配置秒级装载。

### 方法二：终端命令行安装
```bash
dsh plugin add "https://deepseek.stream/api/plugins/download?id=dsh-import-agents"
```
