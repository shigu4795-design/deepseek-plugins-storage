# Agent Vision Toolkit

> **为纯文本模型"看图“设计更好的视觉工具箱和技能，支持多图理解，图片问答，前端UI还原、GUI 自动化等，并可选无缝接入多个主流agent，直接识别粘贴图片｜ A vision toolkit and skill designed for text-only llms — image Q&A, long-screenshot OCR, frontend UI restoration, and GUI automation, with optional seamless integration for Codex, Claude Code, Pi, Oh My Pi, and OpenCode**

## 📖 插件功能与定位

本插件专为 **DeepSeek Harness** 生态量身打造，旨在为用户和开发者解决实际工作流中的核心痛点。

- **插件标识**: `agent-vision-toolkit`
- **当前版本**: `v1.0.0`
- **运行环境**: 全平台通用（支持桌面客户端 EXE、Web 端与终端）
- **开源协议**: MIT License

## ✨ 核心亮点与特性

- ⚡ **开箱即用**：零繁琐环境配置，支持在网页端一键拉起桌面客户端免命令行极速装载；

## ⚡ 极速安装与使用指南

### 方式一：官方桌面客户端一键装载（推荐 ⚡）
1. 访问 **[DeepSeek 插件生态市场 (deepseek.stream)](https://deepseek.stream/plugins/agent-vision-toolkit)**；
2. 在插件卡片右上角点击 **「⚡ 一键安装到桌面版」**；
3. 浏览器将自动唤醒 DeepSeek Harness 桌面客户端并秒级完成装载！

### 方式二：终端命令行安装
打开终端执行以下标准安装指令：
```bash
dsh plugin add "https://deepseek.stream/api/plugins/download?id=agent-vision-toolkit"
```
