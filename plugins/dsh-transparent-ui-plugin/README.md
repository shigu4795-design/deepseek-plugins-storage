## 📖 插件核心亮点 (Highlights)

【实用工具】 是一层高自由度的玻璃质感主题，套在 DeepSeek Harness 网页端。顶栏、侧边栏、输入框、统计行、轨迹视图都成了磨砂玻璃片。玻璃模糊度、磨砂度、背景（流体或自定义壁纸，壁纸还能单独调模糊和磨砂）全都能在设置卡片里自由调节。关掉开关就回到原生界面，不改 DSH 任何一行源码。

### 💡 主要解决痛点与功能：
- ⚡ **开箱即用**：深度适配 DeepSeek Harness 官方桌面端与 Web 端，零繁琐环境配置；
- 🛡️ **安全沙箱**：规范化声明权限，本地沙箱隔离运行，保护工程代码安全；
- 🚀 **一键极速装载**：支持在插件市场网页端一键呼起桌面端自动完成导入。

## ⚡ 极速安装使用教程 (Installation)

### 方式一：官方桌面客户端一键装载（强烈推荐 ⭐）
1. 打开 **[DeepSeek 插件生态市场 (deepseek.stream)](https://deepseek.stream/plugins/dsh-transparent-ui-plugin)**；
2. 点击右上角 **「⚡ 一键安装到桌面版」**；
3. 浏览器将自动拉起 DeepSeek Harness 客户端并秒级完成装载！

### 方式二：终端命令行装载
打开终端执行：
```bash
dsh plugin add "https://deepseek.stream/api/plugins/download?id=dsh-transparent-ui-plugin"
```
