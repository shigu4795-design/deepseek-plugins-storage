# Kun Like Pet

> 互动式桌面陪伴宠物插件，随 Agent 思考与编码状态自动切换可爱动作与反馈音效。

---

## 📖 功能介绍

本插件专为 **DeepSeek Harness** 生态定制打造，旨在为开发者提供高效、流畅的扩展体验。

- **适用平台**：全平台通用（支持桌面端 EXE、Web 端与终端）
- **推荐指数**：⭐⭐⭐⭐⭐ (官方认证精选)
- **开源协议**：MIT License

---

## ✨ 核心特性

- **⚡ 开箱即用**：零繁琐配置，支持在插件市场网页端一键呼起桌面客户端极速装载；
- **🛡️ 安全可靠**：本地沙箱隔离运行，严谨声明权限，保护开发者工程源码安全；
- **🚀 深度集成**：无缝融入 DeepSeek 对话流与工作空间，提升日常 AI 辅助开发效率。

---

## ⚡ 一键安装与使用指引

### 方式一：官方桌面客户端一键装载（推荐 ⚡）
1. 访问 **[DeepSeek 插件生态市场 (deepseek.stream)](https://deepseek.stream/plugins/dsh-kun-like-pet)**；
2. 点击右上角 **「⚡ 一键安装到桌面版」**；
3. 浏览器将自动唤起 DeepSeek Harness 桌面客户端并秒级完成装载！

### 方式二：终端命令行装载
打开终端执行以下命令：
```bash
dsh plugin add "https://deepseek.stream/api/plugins/download?id=dsh-kun-like-pet"
```
