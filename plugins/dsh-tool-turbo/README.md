## 📖 插件介绍

Per-round reasoning_effort optimizer for DeepSeek Harness (dsh): auto-downgrades tool-call reasoning for simple tool chains, lifting back for heavy work. Cuts thinking time between tool calls.

---

## ⚡ 安装方法

### 方法一：桌面客户端一键安装（推荐）
在 [DeepSeek 插件市场](https://deepseek.stream/plugins/dsh-tool-turbo) 点击 **「一键安装到桌面版」** 即可免配置秒级装载。

### 方法二：终端命令行安装
```bash
dsh plugin add "https://deepseek.stream/api/plugins/download?id=dsh-tool-turbo"
```
