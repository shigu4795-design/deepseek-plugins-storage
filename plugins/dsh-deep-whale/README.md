## 📖 简介

**Deep Whale** 是适用于 DeepSeek Harness 桌面端的鲸鱼娘极光蓝系列精美主题皮肤。
包含深海渐变背景、毛玻璃卡片质感与专属图标高光。

---

## ⚡ 安装方法

### 方法一：桌面客户端一键安装（推荐）
在 [DeepSeek 插件市场](https://deepseek.stream/plugins/dsh-deep-whale) 点击 **「一键安装到桌面版」** 即可免配置秒级装载。

### 方法二：终端命令行安装
```bash
dsh plugin --profile web add "github:Minglink/dsh-deep-whale"
```
