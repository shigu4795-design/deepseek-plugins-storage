## 📖 插件介绍

DeepSeek Harness (dsh) 从 0 到 1 深度手册：安装/插件开发/性能调优/实测案例/同模型多 Agent 实测对比（中文 + 英文 PDF）

## ⚡ 安装方法

### 方法一：桌面客户端一键安装（推荐）
在 [DeepSeek 插件市场](https://deepseek.stream/plugins/dsh-handbook) 点击 **「一键安装到桌面版」** 即可免配置秒级装载。

### 方法二：终端命令行安装
```bash
dsh plugin add "https://deepseek.stream/api/plugins/download?id=dsh-handbook"
```
