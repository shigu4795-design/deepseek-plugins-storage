## ⚡ 极速安装使用教程 (Installation)

### 方式一：官方桌面客户端一键装载（强烈推荐 ⭐）
1. 打开 **[DeepSeek 插件生态市场 (deepseek.stream)](https://deepseek.stream/plugins/harness-ai-kit)**；
2. 点击右上角 **「⚡ 一键安装到桌面版」**；
3. 浏览器将自动拉起 DeepSeek Harness 客户端并秒级完成装载！

### 方式二：终端命令行装载
打开终端执行：
```bash
dsh plugin add "https://deepseek.stream/api/plugins/download?id=harness-ai-kit"
```
