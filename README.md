## ⚡ 安装与使用 (Installation)

### 1. 桌面端一键装载（推荐 ⚡）
直接访问 **[DeepSeek 插件市场 (deepseek.stream)](https://deepseek.stream)**，在任意插件卡片上点击 **「⚡ 一键安装到桌面版」**。

### 2. 命令行安装
```bash
# 格式：从官方市场源一键安装
dsh plugin add "https://deepseek.stream/api/plugins/download?id=<plugin-id>"
```
